NUGLIS GAMES BOOKMARKLET

WHAT IT DOES:
Run it on ANY tab (even your school work tab). A clean glass sidebar appears on the left. Hover over the buttons to see labels. Click GAMES and a searchable menu slides open with all the games. Click a game to play it full-screen on top of that tab. CLOSE removes the whole thing.

STEP 1 - GET THE BOOKMARKLET

The whole bookmarklet is in the box below. Click the arrow in the corner to pop it out into a blank tab.

NUGLIS BOOKMARKLET
POP IT OUT with the arrow, then CMD + A and CMD + C READY

STEP 2 - SAVE THE BOOKMARK

  1. Click the arrow in the corner of the box. It pops the bookmarklet open in a blank tab.
  2. In that tab, press Cmd + A to select the whole thing.
  3. Press Cmd + C to copy it.
  4. Go back to your browser, bookmark any tab (search about:blank into your URL bar or go to any website then bookmark it)
  5. Edit that bookmark. In the URL box, delete the old text and paste the copied one (Cmd + V).
  6. In Name type: nuglis games
  7. Click Save, then click the nuglis games bookmark on any tab.

STEP 3 - HOW TO USE IT

  1. Click the nuglis games bookmark on any page.
  2. A popup appears asking ENTER TEH CODE TO UNLOCK → type 5005 (keypad (click the numbers) or keyboard) and hit ENTER. The digits show as *, and wrong codes shake the box.
  3. A loading screen fades out the page and shows nooglis is le goat with a green progress bar → then the black & white sidebar loads in.
  4. A thin white bar appears on the left edge. Hover over it and the black glass dock slides out.
  5. Hover the buttons → they grow and their labels appear. Click GAMES → the game menu slides out.
  6. The games show as cards on an animated white Matrix rain on a black background → click any card to launch that game right inside the menu.
  7. Search the games with the bar at the top.
  8. Hit the X to close the menu, the ← arrow to minimize the dock, or CLOSE to remove everything.
  9. In the game: ← BACK returns to the game list, or FULLSCREEN ↑ makes the popup fill your whole screen (hit Esc or press FULLSCREEN again to shrink it).

TROUBLESHOOTING

Nothing happens when I click the bookmark? Some school pages block running code from bookmarks. Try it on a normal page (YouTube, Google, your school homepage). If it still fails, that page's security blocks it - use it on a page that allows it.

Games need internet Games load from the jsDelivr CDN, so you need to be online.

What games are these? 843 numbered games from the c2265232-dot/html repo - just search the number you want and click it.

What's the unlock code? The code is 5005. Type it on the keypad or the keyboard, then press ENTER.

CMD + A / CMD + C don't select or copy the text? Click inside the box first, or just click once on the text to select it all, then press CMD + C.
